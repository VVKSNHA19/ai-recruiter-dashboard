# AI Recruiter Automation Dashboard

This is an AI-powered recruiter dashboard built using Python and Streamlit.

## Features

- Upload multiple resume PDFs
- Extract skills automatically
- Calculate ATS score
- Predict candidate category
- Save candidate data to Google Sheets
- Export Excel report
- Generate recruiter email drafts

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- PDFPlumber
- Google Sheets API

## Project Workflow

Resume Upload
↓
Skill Extraction
↓
ATS Score
↓
Candidate Ranking
↓
Google Sheets Storage
↓
Excel Export
↓
Recruiter Email Automation
